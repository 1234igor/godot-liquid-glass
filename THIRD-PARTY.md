## Apple

"Liquid Glass" is Apple's name for its own design language. This is an
independent reimplementation for Godot. It is not affiliated with or endorsed
by Apple, and it contains none of Apple's code, shaders or assets.

`validation/reference-swiftui/` is a small SwiftUI application written for this
project. It calls Apple's public `.glassEffect` API so the two can be captured
side by side, in the same way any app would. It is a measuring instrument, not
a copy of anything.
